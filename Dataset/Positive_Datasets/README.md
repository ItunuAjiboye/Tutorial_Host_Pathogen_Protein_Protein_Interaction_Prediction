# Positive Interaction Data
 
This directory contains the curated positive host–pathogen protein-protein interaction (HP-PPI) data for four bacterial pathogens used in this tutorial, along with the corresponding protein sequences.
## Contents
 
- **Interaction data (CSV):** positive host–pathogen protein-protein interaction pairs for all four pathogens.
- **Protein sequences (FASTA):** one file per pathogen, named `pathogenname_genome_feature.fasta`, containing the protein sequences of interaction proteins, both host and pathogen for that specie.
## Usage
 
These files are the input to the dataset preparation and preprocessing notebooks.
