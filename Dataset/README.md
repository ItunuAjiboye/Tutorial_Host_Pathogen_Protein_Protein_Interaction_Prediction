# Data

This folder contains the input data used in the HP-PPI prediction tutorial.

## Contents

- **`Positive_Dataset/`**: Positive host–pathogen protein-protein interaction data for four bacterial pathogens (CSV), plus one FASTA file per pathogen (`pathogenname_genome_feature.fasta`) with the sequences of the interacting host and pathogen proteins.
- **`Proteome Data/`**: The complete set of proteins and sequences for each organism (host and pathogens), used to generate negative interaction pairs.

## Usage

These files are the inputs to Notebook 1 (Dataset preparation). See each subfolder's README for details.
